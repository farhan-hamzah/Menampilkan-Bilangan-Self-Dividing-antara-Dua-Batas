# Menampilkan-Bilangan-Self-Dividing-antara-Dua-Batas
program ini dibuat untuk Self-dividing number adalah bilangan yang habis dibagi oleh setiap digitnya sendiri. Contoh:  128 → ✅ karena 128 % 1 == 0, 128 % 2 == 0, 128 % 8 == 0  120 → ❌ karena 120 memiliki digit 0, dan pembagian dengan 0 tidak valid
